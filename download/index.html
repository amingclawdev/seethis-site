SHA256SUMS · Release notes

Your first two marks

Try this on a document with no private content. A capture includes the entire selected display, so hide private windows and notifications first.

  1. Install and open SeeThis. For the GitHub download, compare the file with the published SHA256SUMS, then move SeeThis.app to Applications and open it. Look for SeeThis in your menu bar.
  2. Allow the capture permissions. In System Settings → Privacy & Security, allow Input Monitoring and Screen Recording for this copy of SeeThis. Reopen it if macOS asks. For Chrome tab/page context, allow Automation when prompted, then release the shortcut and start a fresh gesture.
  3. Circle two places. Hold ⌥ A, drag around the first place and write 1 beside it. Keep holding the shortcut, circle the second place and write 2. Use a mouse drag, a trackpad click-and-drag, or enabled three-finger drag. Release the shortcut to create one reference.
  4. Share the right format. Use the copied local link for a tool on this Mac, or copy the marked image for a web chat, as shown below. Add a short message referring to 1 and 2.

An agent on this Mac

Paste the automatically copied reference into Claude Code, Codex or another local tool that can read it. SeeThis must be running, and the reference must not have expired or been deleted.

A web chat or remote assistant

Choose Show Inspector… from the menu. Once the image is ready, select Copy marked image, check the whole image, then paste or attach it to your chat. Confirm an image preview appears. A 127.0.0.1 link will not work from another computer.

Keeping references and switching versions

References are stored locally. The defaults are 7-day retention and up to 500 searchable references; adjust them in Open Settings… → Reference access.

The App Store version uses its own local data container. It does not automatically import the GitHub version’s references or settings, and permissions may need to be granted again. Before switching, copy or save any marked images you need to keep, quit the old copy, and open the version you intend to use.

For the GitHub version, install new releases manually. Once the App Store version is available, manage its updates through the Mac App Store.
