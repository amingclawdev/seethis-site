How it works

SeeThis lives in your menu bar. The app you are working in stays in front the whole time.

1

Hold the shortcut and mark

Hold ⌥ A to turn on marking, then press the left mouse button and drag around what you mean, in any app or window. Keep holding ⌥ A to add more marks to the same reference. In Google Chrome, marks remember their tab and page.

2

Release to get a reference

Release ⌥ A to finish. A local reference URL is copied right away for agents on the same Mac, such as Claude Code or Codex. For web chats, copy the marked image from Inspector.

3

Paste and ask

Paste the reference into your agent with a short message. Write numbers next to your marks and say “1: …, 2: …”, and the agent knows which point is which.

One reference, two numbered marks

Reviewing a document with an agent, circle a sentence and write a 1 next to it, circle a section and write a 2, then send one line:

1 is a use case. 2: would a website be better for statistics and SEO?

The agent matches each point to its mark and answers both. One message instead of two paragraphs of directions.

Why not just a screenshot?

You can always take a screenshot and type a description. SeeThis is for when that gets slow: several points at once, small details, or the same spot again later.

Private by default

  • SeeThis does not upload your screen to a cloud service.
  • Reference URLs use 127.0.0.1, so they only work for tools on the same Mac while SeeThis is running.
  • A capture includes the whole selected display. Marks are not a privacy crop, so hide private windows first and check the image before you share it.

Privacy details

What you need

  • A Mac with Apple Silicon, macOS 14.2 or later.
  • Input Monitoring, so SeeThis can see the shortcut while another app is in front, and Screen Recording, to capture what you marked.
  • Optional: Automation access to Google Chrome, for tab and page context.
  • It is distributed directly, not through the Mac App Store, because the App Store does not allow Input Monitoring.

FAQ

Is SeeThis free?

Yes. SeeThis is open source under the MIT license.

Which AI tools does it work with?

Agents running on the same Mac, such as Claude Code or Codex, can read the local reference URL directly. For web chats and remote assistants, paste or attach the marked image.

Does it work on Intel Macs or Windows?

Not yet. The current beta is for Apple Silicon Macs on macOS 14.2 or later.

Does it update automatically?

Not yet. New versions are published on the GitHub releases page.

How do I give feedback?

Choose Feedback… in the menu bar to open an email draft, or open an issue on GitHub.
