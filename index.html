What the four sessions above rely on.

Append screenshots

Turn it on for a reference in Inspector, then capture another tab, another app or the next version. Each capture adds a shot, and the numbers keep counting: 1 and 2 on the listing, 3, 4 and 5 on the contract.

A note for each number

Click a numbered badge and type what you mean. The note stays with its mark while you look at other things. Closing the note saves it and copies the reference link.

One link carries it all

An agent on the same Mac reads every shot, mark and note from one local link. For a web chat, pick the shot you need in Inspector and copy its marked image.

How it works

SeeThis lives in your menu bar. Before your first capture, allow Input Monitoring and Screen Recording. Then try two marks on a document you can safely share. First-use steps →

1

Hold the shortcut and mark

Hold ⌥ A and drag around what you mean with the left mouse button, or with three fingers on a trackpad, in any app or window. Keep holding to add more marks. Each one gets a number. In Google Chrome, marks remember their tab and page.

2

Release to get a reference

Release ⌥ A. A local reference link is copied to your clipboard automatically. Need another tab or app in the same request? Turn on Append screenshots in Inspector and mark again.

3

Paste and ask

Add a note to any number, or just write “1: …, 2: …” in your message. Agents on the same Mac, such as Claude Code or Codex, read the link. For web chats, copy the marked image from Inspector.

Return to a saved reference

References are saved on your Mac with their source app and time. Open Inspector and choose a reference that has not expired or been deleted.

  • Copy its link again to use it in a new agent session.
  • Edit its notes, then send the same link again.
  • Copy a marked image for web chats, view the details, or delete references you no longer need.

Default limits: 7-day retention and up to 500 searchable references. Change them in Open Settings… → Reference access.

Why not just a screenshot?

You can always take a screenshot and type a description. SeeThis is for when that gets slow: several points at once, small details, several apps, or the same spot again later.

Private by default

  • SeeThis does not upload your screen to a cloud service.
  • Reference URLs use 127.0.0.1, so they only work for tools on the same Mac while SeeThis is running.
  • A capture includes the whole selected display. Marks are not a privacy crop, so hide private windows first and check the image before you share it.
  • A reference can include the window title and, in Chrome, the page URL.

FAQ

Is SeeThis free?

Yes. SeeThis is open source under the MIT license.

Which AI tools does it work with?

Agents running on the same Mac, such as Claude Code or Codex, can read the local reference URL directly, including every shot, mark and note. For web chats and remote assistants, such as ChatGPT in the browser, paste or attach the marked image.

Where can I get 0.1.5?

Get it free from the Mac App Store, or download the signed and notarized DMG or ZIP from GitHub: see the download page.

Can I draw with a trackpad?

Yes. Hold ⌥ A, then click and drag, or use three-finger drag if it is turned on in System Settings → Accessibility → Pointer Control → Trackpad Options.

Does it work on Intel Macs or Windows?

Not yet. SeeThis 0.1.5 is for Apple Silicon Macs on macOS 14.2 or later.

How do updates work?

Install and update the App Store version through the Mac App Store. The GitHub version has no automatic updater; download new releases manually from GitHub releases.

Will my GitHub references move to the App Store version?

The App Store version keeps its own local data. It does not automatically import the GitHub version’s references or settings, and permissions may need to be granted again. Keep any images you need before switching, and quit the old copy before opening the other version. Switching versions →

How long are references saved?

The defaults are 7-day retention and up to 500 searchable references. Adjust these in Open Settings… → Reference access. Expired or deleted references cannot be reused through their local links.

How do I give feedback?

Choose Feedback… in the menu bar to open an email draft, or open an issue on GitHub.
